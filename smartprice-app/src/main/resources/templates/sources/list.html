Cómo se obtienen los datos

Del archivo original a la pantalla

  1. Exportación de SISAP (tabla HTML con extensión .xls, Latin-1).
  2. Lectura y conversión a formato largo (job Java sisap-to-csv).
  3. Carga en MongoDB Atlas con Apache Spark, sin duplicados (load-sisap).
  4. Indicadores y alertas con Apache Spark (batch-analytics).
  5. Boletines diarios nuevos con Spark Structured Streaming (ingest-pdf + stream-prices).
  6. Esta aplicación (Spring Boot) solo lee los resultados.
